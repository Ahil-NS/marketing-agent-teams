# TikTok Publishing Guide

## Video Specifications
- Format: MP4 or WebM
- Resolution: 1080x1920 (9:16 vertical)
- Max file size: 287.6 MB (API)
- Duration: 3 seconds to 10 minutes

## API Publishing
- Use TikTok Content Posting API
- Handle OAuth token refresh
- Implement retry logic for transient failures
- Track publish status (processing, published, failed)

## Caption Optimization
- Max 2,200 characters
- Front-load key message
- Include 3-5 relevant hashtags
- Add CTA when appropriate

## Post-Publish Monitoring
- Track views in first 30 minutes
- Monitor completion rate
- Check for sharing activity
- Flag for boost if underperforming

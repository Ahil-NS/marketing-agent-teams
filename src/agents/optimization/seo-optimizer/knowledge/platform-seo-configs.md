# Platform SEO Configuration Reference (2026)

## TikTok SEO Configuration

### Character Limits
| Element | Max | Optimal |
|---|---|---|
| Caption | 4,000 | 150 |
| Body | 4,000 | 150 |

### Hashtag Strategy
- Range: 3-5 hashtags per post
- Avoid generic: #fyp, #foryou, #foryoupage, #viral
- Use niche, keyword-specific hashtags

### 4 Indexable Layers
TikTok's search algorithm indexes content across 4 distinct layers:

1. **Caption Text Layer**
   - Max 4,000 characters
   - Keywords in first line receive maximum indexing weight
   - Primary keyword should appear within the first sentence

2. **OCR Text Overlay Layer**
   - On-screen text is scanned via OCR and indexed
   - Include primary keyword in text overlays
   - Provides double-indexing with caption text

3. **Audio Keywords Layer**
   - TikTok transcribes spoken audio for search
   - Include primary keyword in spoken audio within first 5 seconds
   - Audio-text alignment boosts search ranking

4. **Hashtags Layer**
   - 3-5 niche hashtags (avoid generic tags)
   - Hashtags serve as topic categorization signals
   - Trending hashtags increase initial distribution

### Ranking Signals
- Watch time (highest weight)
- Shares
- Comments
- Profile visits
- Saves

## Reddit SEO Configuration

### Character Limits
| Element | Max | Optimal |
|---|---|---|
| Title | 300 | 60 |
| Body | 40,000 | 400 |

### Key Rules
- **Zero hashtags** — Reddit does not use hashtags
- **Title keyword front-loading**: Place keywords at the start of the title
- **Optimal post length**: 300-500 words for maximum engagement
- **Google Search Visibility**: Reddit posts are heavily indexed by Google. Optimize titles and first paragraphs for Google SERP capture.

### Ranking Signals
- Upvotes
- Comment count
- Awards
- Crosspost count

## Facebook SEO Configuration

### Character Limits

|---|---|---|
| Body | 63,206 | 60 |

### Key Rules
- **1-2 hashtags** maximum (more reduces reach)
- **Comment-weight optimization**: Posts that generate comments rank higher
- **Video preference signal**: Algorithm favors video content
- **Share-optimized formatting**: Use line breaks and emojis for scannability

### Ranking Signals
- Comments (highest weight)
- Shares

## Instagram SEO Configuration

### Character Limits
| Element | Max | Optimal | Visible Preview |
|---|---|---|---|
| Caption | 2,200 | 150 | 125 |
| Alt Text | 125 | 110 | — |

### Key Rules
- **Alt text required**: 100-125 characters, descriptive with keywords
- **3-5 hashtags** (official Instagram 2026 recommendation)
- **Caption keyword zone**: First 125 visible characters before "more" truncation — place primary keywords here
- **Saves + shares** are weighted highest by the Instagram algorithm (2026)

### Ranking Signals
- Saves (highest weight)
- Shares
- Comments
- Profile visits
- Follows

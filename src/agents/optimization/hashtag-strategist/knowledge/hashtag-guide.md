# Hashtag Strategy Guide

## Hashtag Categories
- **Broad** (1M+ posts): High reach, high competition (limit 1-2)
- **Medium** (100K-1M): Balanced reach and discoverability (3-5)
- **Niche** (10K-100K): Targeted, lower competition (3-5)
- **Micro** (<10K): Very targeted community (1-2)
- **Branded**: Campaign or company specific (1-2)

## Platform-Specific Counts
- **Instagram**: 5-15 per post (quality over quantity)
- **TikTok**: 3-5 per video (trending + niche mix)
- **Twitter/X**: 1-3 per tweet
- **Facebook**: 1-3 per post (less important)
- **Reddit**: Not applicable (use flair instead)

## Best Practices
- Rotate hashtag sets — don't use same set every post
- Research before using — check what content appears
- Avoid banned or flagged hashtags
- Create branded hashtags for campaigns
- Monitor hashtag performance monthly
- Include community-specific hashtags

## Anti-Patterns
- Using only broad hashtags (content gets buried)
- Using irrelevant trending hashtags (damages credibility)
- Copy-pasting same hashtag set repeatedly
- Using banned hashtags (shadowban risk)

# A/B Testing Methodology

## Test Design Principles
- One variable at a time for clean results
- Sufficient sample size before concluding
- Run tests for full business cycle (min 7 days)
- Document everything: hypothesis, setup, results
- Always link variations back to original content items

## Variation Types Taxonomy

### Hook Variations
- **Question hook**: Opens with curiosity-driven question ("Did you know...?")
- **Statistic hook**: Leads with surprising data point ("90% of marketers...")
- **Controversial hook**: Bold contrarian statement to drive debate
- **Story hook**: Personal anecdote or mini-narrative opening
- **How-to hook**: Promise of practical knowledge ("Here's how to...")
- Best for testing: Click-through rate, scroll-stop rate, view duration

### Caption Variations
- **Length**: Short (1-2 lines), medium (3-5 lines), long (full paragraph)
- **Emoji density**: None, sparse (1-2), heavy (3+)
- **Structure**: Single block, line breaks, bullet points, numbered list
- **Tone shift**: Formal vs. casual vs. humorous (within brand guidelines)
- Best for testing: Engagement rate, read-through rate, save rate

### Hashtag Variations
- **Count strategy**: Minimal (1-3), moderate (5-8), maximum (15-30 on Instagram)
- **Specificity mix**: Broad vs. niche vs. branded vs. trending
- **Placement**: Inline (within caption), end-of-caption, first comment (Instagram)
- **Freshness**: Evergreen vs. trending vs. seasonal vs. event-based
- Best for testing: Reach, impressions, discovery rate

### Format Variations
- **Content structure**: Listicle, narrative, how-to guide, comparison, case study
- **Media type**: Static image, carousel, short video, long video, text-only
- **Visual style**: Polished vs. raw/authentic, branded template vs. organic
- Best for testing: Engagement rate, share rate, completion rate

### CTA Variations
- **Urgency level**: Soft ("learn more"), direct ("download now"), urgent ("limited time")
- **Placement**: Opening line, mid-content, closing, multiple touchpoints
- **Type**: Action ("click"), value ("get free guide"), social proof ("join 10K others")
- **Format**: Text link, button-style, bio reference, comment-based
- Best for testing: Click-through rate, conversion rate, link clicks

## Social Media Content Testing Best Practices

### Platform-Specific Guidance

**Reddit**
- Test title hooks heavily — Reddit is title-driven
- Question titles vs. statement titles show different engagement patterns
- Self-post length matters: test concise vs. detailed
- Subreddit-appropriate tone is critical — test formality levels
- Avoid hashtags (Reddit doesn't use them)

**TikTok**
- First 1-3 seconds determine retention — test hook variations aggressively
- Text overlay vs. spoken hook — test both modalities
- Caption length has minimal impact vs. video hook — prioritize video opening
- Hashtag count sweet spot: 3-5 relevant tags
- Sound/music choice is a testable variable

**Facebook**
- Longer posts can outperform short ones — test length
- Video posts get priority in algorithm — test format
- Question posts drive comments — test hook type
- Emoji usage varies by audience demographic — test density
- Link placement: in-post vs. first comment affects reach

**Instagram**
- Carousel posts have highest save rate — test format
- First slide is the hook — test visual + text opening
- Caption length: short vs. long depends on niche
- Hashtag strategy: test 5 vs. 15 vs. 30
- CTA placement: caption end vs. final carousel slide

### Statistical Significance
- Minimum 95% confidence level for decisions
- Calculate minimum sample size before test starts
- Don't peek and conclude early
- Account for multiple comparison corrections
- Use Bonferroni correction when running multiple simultaneous tests

### Test Duration Guidelines
- Minimum 7 days to capture weekly posting rhythm
- 14 days ideal for more statistical power
- Account for seasonal/event effects
- Don't test during holidays or unusual traffic periods
- Ensure each variation gets equal exposure (publish at same time/day)

### Interpreting Results
- Focus on primary metric, note secondary effects
- Consider practical significance vs. statistical significance
- Document learnings regardless of outcome
- Plan follow-up tests to confirm findings
- Build a hypothesis-result knowledge base over time

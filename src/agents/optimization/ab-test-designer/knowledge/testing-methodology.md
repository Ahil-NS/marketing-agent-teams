# A/B Testing Methodology

## Test Design Principles
- One variable at a time for clean results
- Sufficient sample size before concluding
- Run tests for full business cycle (min 7 days)
- Document everything: hypothesis, setup, results

## Common Content Tests
- **Hook variations**: Different opening lines/visuals
- **CTA placement**: Beginning vs. end vs. throughout
- **Format**: Video vs. carousel vs. static
- **Length**: Short-form vs. long-form
- **Tone**: Professional vs. casual vs. humorous
- **Timing**: Different posting times/days

## Statistical Significance
- Minimum 95% confidence level for decisions
- Calculate minimum sample size before test starts
- Don't peek and conclude early
- Account for multiple comparison corrections

## Interpreting Results
- Focus on primary metric, note secondary effects
- Consider practical significance vs. statistical significance
- Document learnings regardless of outcome
- Plan follow-up tests to confirm findings

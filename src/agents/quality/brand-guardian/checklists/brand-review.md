# Brand Review Checklist

## Voice & Tone
- [ ] Content matches brand voice guidelines
- [ ] Tone is appropriate for platform
- [ ] Language level matches target audience
- [ ] Brand personality traits are present

## Messaging
- [ ] Core message aligns with brand positioning
- [ ] Value proposition is clear
- [ ] No contradictory claims
- [ ] CTAs match brand style

## Vocabulary
- [ ] Brand-specific terms used correctly
- [ ] No prohibited words or phrases
- [ ] Jargon level is appropriate
- [ ] Consistent terminology throughout

## Visual (if applicable)
- [ ] Color palette matches brand guidelines
- [ ] Typography follows brand standards
- [ ] Logo usage is correct
- [ ] Visual style is on-brand

## Overall
- [ ] Content would be recognized as this brand
- [ ] No brand risk issues
- [ ] Quality meets brand standards

# Social Media Analysis Methods

## Platform-Specific Analysis (Scraping-Free)

All analysis is conducted via WebSearch — no API scraping or unauthorized access.

### Reddit Analysis
- Search `site:reddit.com "[competitor name]"` to find brand mentions
- Analyze competitor-related subreddit discussions for sentiment
- Look for competitor AMAs, official accounts, and promotional posts
- Track competitor product launch discussions and user feedback
- Monitor r/[industry] subreddits for competitive mentions
- Note: Reddit's public search is comprehensive for brand monitoring

### TikTok Analysis
- Search `site:tiktok.com "@[competitor handle]"` for profile discovery
- Use TikTok Creative Center (trends.tiktok.com) for competitor hashtag performance
- Search competitor brand hashtags for UGC and branded content volume
- Analyze competitor video description patterns and CTA styles
- Note: Focus on publicly visible metrics — views, likes, comments, shares

### Instagram Analysis
- Search competitor brand name + Instagram for profile metrics
- Use third-party analytics summaries (public reports, press mentions)
- Analyze competitor hashtag strategies via hashtag search
- Look for competitor influencer partnerships and tagged content
- Note: Most metrics require public profile analysis — no private data access

### Facebook Analysis
- Search competitor Facebook page for public posting patterns
- Analyze page transparency reports (available publicly on Facebook)
- Monitor competitor group activity and community engagement
- Check ad library (facebook.com/ads/library) for competitor ad strategies
- Note: Facebook Ad Library is a public resource for competitor ad research

## Cross-Platform Analysis Patterns
1. **Consistent messaging**: Does the competitor say the same thing everywhere, or adapt per platform?
2. **Cross-posting patterns**: Are they repurposing content or creating platform-native?
3. **Platform prioritization**: Where do they invest the most effort and budget?
4. **Audience segmentation**: Do they target different audiences per platform?

## Data Quality for Competitive Analysis
- Use web search results from the last 30-90 days for freshness
- Cross-reference engagement claims across multiple sources
- Note when data is estimated vs. confirmed
- Always include the date range of analysis
- Distinguish between organic and paid content performance

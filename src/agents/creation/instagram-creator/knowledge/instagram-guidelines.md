# Instagram Content Guidelines

## Format Best Practices

### Reels
- First frame must stop the scroll
- Keep 15-30 seconds for highest completion rate
- Use trending audio within first 48 hours
- On-screen text for sound-off viewing
- Pattern interrupts every 3-5 seconds

### Carousels
- First slide is the hook — must earn the swipe
- 5-10 slides for optimal engagement
- Each slide should deliver standalone value
- Last slide: CTA or summary
- Consistent visual style across slides

### Stories
- Use interactive stickers (polls, quizzes, questions)
- 3-7 frames per story sequence
- Mix media types (photo, video, text)
- Include link stickers for conversion

### Static Posts
- Strong visual with clear focal point
- Text overlays for context when needed
- Maintain grid aesthetic consistency

## Hashtag Strategy
- 5-15 hashtags per post
- Mix: 2-3 broad + 5-7 niche + 2-3 brand
- Research hashtag size (avoid 1M+ for small accounts)
- Place in first comment or caption (both work)

## Caption Optimization
- Start with hook line (shown before "...more")
- Provide value in body
- End with CTA or question
- Use line breaks for readability
- Include relevant emojis sparingly

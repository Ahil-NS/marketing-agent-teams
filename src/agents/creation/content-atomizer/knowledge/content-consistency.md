# Content Consistency Across Atomized Pieces

## Brand Voice Preservation

### Voice Adaptation Rules
- Core brand voice elements (tone, values, banned phrases) apply to ALL atomized content
- Platform-specific voice adaptations are permitted within brand voice boundaries
- Reddit: more casual, community-member tone; still respect brand principles
- TikTok: energetic, concise, trend-aware; maintain authenticity
- Facebook: community-oriented, conversational; preserve professionalism
- Instagram: aspirational, visual-first language; keep brand aesthetic

### Consistency Checklist
- [ ] Same core message across all atomized pieces
- [ ] No contradicting claims between platforms
- [ ] Brand terminology used consistently
- [ ] Banned phrases excluded from ALL pieces
- [ ] Tone variations stay within brand voice spectrum

## Messaging Hierarchy

### Primary Message
- The single most important takeaway from the source content
- Must appear in some form in every atomized piece
- Adapted for each platform's native format

### Supporting Points
- 2-3 secondary messages that reinforce the primary
- Can be distributed across platforms (not all need every supporting point)
- Each platform gets the supporting point most relevant to its audience

### Evidence & Proof
- Statistics, quotes, case studies that back up messages
- Distribute evidence strategically — heaviest evidence on credibility platforms (Reddit, LinkedIn)
- Visual evidence (before/after, data viz) for visual platforms (Instagram, TikTok)

## CTA Alignment

### Cross-Platform CTA Strategy
- All CTAs should drive toward the same campaign objective
- Platform-appropriate CTA formats:
  - Reddit: "Check out [link]" or discussion prompt
  - TikTok: "Follow for more" or "Save this"
  - Facebook: "Share your experience" or "Join the conversation"
  - Instagram: "Save for later" or "Link in bio"
- Never use aggressive sales CTAs on community platforms (Reddit, Facebook Groups)

## Cross-Platform Linking Strategy

### Content Sequencing
- Create content that references other platform content without requiring it
- "I shared more about this in a longer thread on Reddit" (in TikTok caption)
- "See the carousel breakdown on Instagram for the full framework" (in Facebook post)
- Each piece must stand alone — cross-references are bonuses, not requirements

### Traceability Requirements
- Every atomized piece MUST reference its source content ID
- Source section must be specific (e.g., "Key Statistics" not just "the article")
- Traceability enables the review queue to show source context alongside atomized content
- Format: `{sourceContentId}#{section-slug}` (e.g., "calendar-entry-001#key-statistics")

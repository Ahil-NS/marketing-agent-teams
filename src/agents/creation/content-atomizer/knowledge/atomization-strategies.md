# Content Atomization Strategies

## Pillar Content Strategy

A pillar content strategy treats long-form content as the "pillar" from which all
derivative micro-content flows. The pillar is the authoritative source, and each
atomized piece serves as a gateway back to the pillar or as standalone value.

### Pillar → Micro-Content Cascade

1. **Blog Post / Article** (pillar)
   → Social threads (Reddit, Twitter/X)
   → Carousel slides (Instagram, LinkedIn)
   → Video scripts (TikTok, Reels)
   → Discussion posts (Facebook Groups)
   → Quote graphics (Instagram, Facebook)

2. **Campaign Theme** (pillar)
   → Platform-specific posts highlighting different angles
   → Data visualization posts from campaign statistics
   → Q&A content from campaign FAQs
   → Behind-the-scenes content from campaign process

## Content Extraction Techniques

### Pull Quotes
- Extract impactful sentences that stand alone
- Choose quotes with emotional resonance or surprising insights
- Ensure the quote makes sense without surrounding context
- Add attribution or context wrapper if needed

### Key Statistics
- Extract numerical data points that are attention-grabbing
- Frame stats with "Did you know?" or contrarian angles
- Pair stats with visual formats (infographics, carousel slides)
- Add context to prevent misinterpretation

### Actionable Tips
- Extract step-by-step instructions or how-to segments
- Format as numbered lists for easy scanning
- Each tip should deliver standalone value
- Create "3 things" or "5 ways" formatted content

### Story Angles
- Identify narrative elements: problem, solution, transformation
- Extract before/after scenarios
- Find personal anecdotes or case studies
- Create "what I learned" or "confession" style content

## Content Cascade Model

### Comprehensive Atomization
Extract ALL possible micro-content from the source. Best for high-value pillar content
that warrants maximum distribution. Produces 8-15 micro-content pieces across all platforms.

### Highlights Atomization
Extract only the top 3-5 most impactful elements. Best for supporting content or
time-sensitive campaigns. Produces 3-5 micro-content pieces targeting highest-value platforms.

### Key Points Atomization
Extract the core message and 1-2 supporting points. Best for simple announcements or
narrow-topic content. Produces 2-3 micro-content pieces for primary platforms.

## Format Transformation Patterns

| Source Format | Target Format | Transformation |
|---|---|---|
| Article paragraph | Reddit thread section | Add discussion hooks, reduce formality |
| Data table | Instagram carousel | One stat per slide, visual hierarchy |
| How-to steps | TikTok script | "3 things" format, hook-first ordering |
| Case study | Facebook post | Question-led format, community discussion |
| Expert quote | Instagram quote graphic | Visual framing, brand typography |
| FAQ section | Reddit AMA-style | Discussion starters, community Q&A |
| Process description | TikTok "day in the life" | Show don't tell, visual scripting |

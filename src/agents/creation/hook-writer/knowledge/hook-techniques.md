# Hook Writing Techniques

## Psychological Triggers
- **Curiosity gap**: "The one thing most people get wrong about..."
- **Social proof**: "Over 10,000 people have already..."
- **Urgency**: "Before this trend disappears..."
- **Contrarian**: "Stop doing X — here's why..."
- **Identity**: "If you're a [X], you need to know..."
- **Specificity**: Use concrete numbers and details
- **Story opening**: "Last week, something unexpected happened..."

## Platform-Specific Hook Patterns

### Reddit
- Informative, genuine, question-based
- Avoid superlatives and hype language

### TikTok
- Visual + text hook in first 2 seconds
- "Wait for it" and reveal patterns
- Direct address to viewer

### Instagram
- Caption hook: first 125 characters visible
- Visual hook: first frame/image
- Carousel hook: first slide earns the swipe

### Facebook
- Short text hooks for mobile News Feed
- Question hooks drive comments
- Controversial (not offensive) takes drive shares

## Hook Testing Framework
- Generate minimum 5 variations per content piece
- Vary: trigger type, length, tone, structure
- Score by: clarity × relevance × emotional impact
- A/B test top 2 hooks when possible

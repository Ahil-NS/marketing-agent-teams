# Platform Hook Constraints

## Reddit

### Title/Hook Constraints
- **Maximum title length**: ~300 characters
- **Visible in feed**: Full title displayed (no truncation in most clients)
- **No clickbait tolerance**: Subreddit communities actively downvote and remove clickbait
- **Bracket conventions**: Use [Guide], [Discussion], [OC], [Advice], [Question], [Tips] for context

### Content Norms
- Informative, genuine, question-based hooks perform best
- Avoid superlatives ("BEST EVER", "AMAZING", "YOU WON'T BELIEVE")
- Avoid hype language and exclamation marks
- Self-promotion must follow 90/10 rule: 90% value, 10% promotion
- Reddit karma heavily penalizes perceived advertising or manipulation

### Hook Best Practices
- Lead with value — what will the reader learn or gain?
- Use question format to invite discussion (drives comment engagement)
- Reference personal experience for credibility ("After 5 years of...")
- Be specific: numbers, timeframes, concrete details
- Respect subreddit culture — lurk before posting

### What NOT to Do
- Never use engagement bait ("Upvote if you agree!")
- Never use misleading titles — Reddit communities will call it out
- Never use emoji in titles (most subreddits consider it spammy)
- Never cross-post identical content to 10+ subreddits simultaneously

## TikTok

### Title/Hook Constraints
- **The 2-second rule**: Must capture attention within first 2 seconds or viewer swipes
- **On-screen text hook**: 5-10 words maximum, large readable font
- **Caption length**: Up to 4,000 characters (but first ~100 visible without expansion)
- **Spoken hook**: First words spoken must match or complement on-screen text

### Visual + Text Hook Integration
- Hook is a combination of: on-screen text + first visual frame + spoken words
- All three must work together — misalignment loses viewers instantly
- Visual motion or unusual imagery in first frame stops the scroll
- Text hooks should appear within 0.5 seconds of video start

### Hook Patterns That Work
- Direct address: "You need to hear this" (creates personal connection)
- "Wait for it" pattern: Tease a reveal that pays off later (drives completion)
- "POV:" pattern: Immerses viewer in a relatable scenario
- "Things [identity] do" pattern: Identity-based engagement
- "Day in the life" pattern: Authentic and relatable

### Engagement Mechanics
- First 2 seconds determine watch-through rate (most critical metric)
- Completion rate > likes/comments for algorithm
- Loop hooks (ending that connects to beginning) boost replay value
- Text hooks that prompt comments ("Comment your [X]") drive engagement

### What NOT to Do
- Never start with a logo or brand intro (instant swipe)
- Never use a slow build-up — TikTok demands immediate engagement
- Never use text so small it's unreadable on mobile
- Never use hooks that don't pay off — TikTok punishes drop-off

## Facebook

### Title/Hook Constraints
- **Preview text cutoff**: ~125 characters before "See More" on mobile
- **Link post headline**: Displayed below shared link preview — must drive click-through
- **Character visibility**: First 3 lines visible in News Feed without expansion
- **Video hooks**: First 3 seconds auto-play in feed (usually muted)

### Hook Strategies by Post Type
- **Text posts**: Question hooks drive comments; contrarian takes drive shares
- **Link posts**: Headline is the hook — must create curiosity gap for click-through
- **Image posts**: Caption hook must complement visual — visual stops scroll, text converts
- **Video posts**: First 3 seconds must work WITHOUT audio (auto-play is muted)
- **Stories**: First frame must communicate value instantly

### Community-Oriented Hooks
- Questions that invite genuine discussion (not engagement bait)
- Group-specific hooks that reference shared identity
- Polls and "this or that" format for low-friction engagement
- Behind-the-scenes or "real talk" hooks for authenticity

### What NOT to Do
- **NEVER use engagement bait patterns**: "Tag a friend who...", "Like if you agree", "Share to enter"
- Facebook actively demotes engagement bait in algorithm
- Never use ALL CAPS for entire hook (looks like spam)
- Never make claims without backing them up — Facebook audiences fact-check
- Never ignore the "See More" cutoff — your most important words go first

## Instagram

### Title/Hook Constraints
- **Caption preview**: ~125 characters visible before "...more" truncation
- **Carousel first slide**: THIS IS THE HOOK — must earn the swipe
- **Reels opening frame**: First 1-2 seconds determine completion rate
- **Stories**: Each frame has ~5 seconds of attention
- **Bio link CTA**: Must connect hook → caption → action seamlessly

### Hook Strategies by Format
- **Static posts**: Caption hook (125 chars) + visual hook (image that stops scroll)
- **Carousels**: First slide = hook slide. Must promise value worth swiping for. Text on slide must be readable without zooming.
- **Reels**: Opening 2 seconds = verbal + visual hook. Text overlay appears immediately.
- **Stories**: First frame must communicate what the viewer gains. Use polls/quizzes as interactive hooks.

### Algorithm-Optimized Hooks
- Saves are the highest-value engagement signal — hooks that promise "save-worthy" content rank higher
- Share-worthy hooks: Contrarian takes, relatable observations, useful tips
- Comment-driving hooks: Questions, incomplete lists ("What would you add?"), controversial opinions
- "Save this for later" is a legitimate CTA on Instagram (not engagement bait)

### Visual Hook Requirements
- First visual must be scroll-stopping: bright colors, faces, unexpected compositions
- Text on images: 3-7 words, high contrast, readable at thumbnail size
- Carousel cover slides: Must look like a "mini magazine cover" — headline + visual hook

### What NOT to Do
- Never bury the hook after 125 characters — most won't tap "...more"
- Never use generic stock imagery as the visual hook
- Never write carousel first slides that don't promise value
- Never start Reels with "Hey guys" or brand logos (immediate scroll-past)

## Cross-Platform Hook Length Reference

| Platform | Format | Hook Length Limit | Key Constraint |
|---|---|---|---|
| Reddit | Post title | ~300 chars | No clickbait, bracket conventions |
| TikTok | On-screen text | 5-10 words | Must work in 2 seconds |
| TikTok | Caption | ~100 chars visible | Hashtags often take priority |
| Facebook | Text post | ~125 chars before "See More" | Must drive meaningful interaction |
| Facebook | Link headline | ~60-80 chars | Must drive click-through |
| Instagram | Caption | ~125 chars before truncation | Must work with visual |
| Instagram | Carousel slide 1 | 3-7 words text overlay | Must earn the swipe |
| Instagram | Reels | 2-second window | Visual + text + audio hook |
